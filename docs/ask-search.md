# Ask period and amount phrases

Ask resolves named months in English, Hindi and Malayalam to the latest occurrence through the
current month. It supports explicit month ranges and periods such as the last several months. A
future or ambiguous named month and a calendar day without a supported date context request
clarification. Literal merchant queries stop before a date phrase, so the date isn't mistaken for a
payee. Explicit rupee amounts may use lakh, crore or thousand-scale words; those amounts are
converted to paise before the affordability checks.

The assistant remains read-only. Figures continue to come from the household money engine. Search
phrasing does not grant a new provider, route or data source access.
